# Portfolio — Hamza Denis

Site statique (HTML / CSS / JS, sans dépendance ni build).

- `index.html` — tout le contenu du site
- `styles.css` — design (thème bleu marine)
- `script.js` — animations et interactions
- `assets/img/` — photos et visuels

Pour le voir en local : ouvrir `index.html` dans un navigateur, ou `python3 -m http.server`.

En ligne sur **https://hamzadenispro.github.io** (GitHub Pages, branche `main`).
